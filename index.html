How it works underneath

Metadata Parsing: The client-side parser reads the XML file, extracting sequence frame rates, absolute clip tracks, and paths to external references.
02
Multimodal Vector Alignment: DeepCut matches the timeline sequence coordinates against a lightweight cloud proxy that evaluates target visual and audio hashes.
03
EDL Manifest Return: The audit generates a standard markers file that can be loaded straight back into NLE software to display warnings exactly on the editor's timeline ruler.
